# Day 28 Theory - Role Based Authorization

## Authentication vs Authorization

Authentication:

* Verifies identity

Authorization:

* Verifies permissions

---

## What is Role Based Access Control

RBAC restricts access based on user roles.

Examples:

* Admin
* User
* Moderator

---

## Why Authorization Matters

Protects:

* Admin routes
* Sensitive APIs
* User management systems

---

## Real World Usage

Used in:

* Banking systems
* CMS dashboards
* Company admin portals
* SaaS platforms
